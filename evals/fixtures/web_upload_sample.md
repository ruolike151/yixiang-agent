# 上传面板的样张

这个文件是给 Web 控制台「上传文件」用的最小样张：体积小、纯文本、内容可预期。

## 怎么用

1. `uv run yixiang web` 起服务，浏览器打开 <http://127.0.0.1:8765/>；
2. 「对话」面板点「上传文件」，选这份 `evals/fixtures/web_upload_sample.md`；
3. 文件会以 `data/uploads/YYYY-MM-DD-web_upload_sample.md` 落盘（同一天重复上传会加序号，不覆盖）；
4. 接着对模型说「看看我刚上传的文件」，它会调 `read_file` 读 `uploads/` 下那一份。

## 为什么要专门有一份

上传这件事有两条容易踩的坑：一是浏览器把文件塞进 multipart 的时候字段名/文件名丢了一个，
二是文件落了盘但模型没有读它的工具。第 4 步同时验证这两条——`read_file` 读得到，
说明上传的字节确实到了 `data/` 里。

## 可验证的事实

- 标题里的关键词：**以湘上传样张**；
- 本文件的字符数不大，`read_file` 默认 1500 字上限不会截断。
